# 🏃‍♂️ Nike Store - React & Tailwind CSS

A modern, responsive e-commerce frontend for Nike products built with React and Tailwind CSS.

## 🚀 Features

- **Modern UI Design** - Clean Nike-inspired interface
- **Fully Responsive** - Perfect on desktop, tablet & mobile
- **React Powered** - Modern React hooks and components
- **Tailwind CSS** - Utility-first styling
- **Smooth Animations** - Enhanced user experience
- **Product Showcase** - Beautiful product displays
